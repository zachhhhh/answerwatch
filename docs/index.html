What AI models won't tell you

AnswerWatch asks the same questions to many AI models, in English and in Simplified and Traditional Chinese, and checks whether each answer refuses, leaves out key facts, or drops facts that the model's own reasoning contained. Everything here is open: questions, code and raw answers.

Refusals and missing facts, by model and language

Sensitive questions cover topics such as Tiananmen 1989, Xinjiang, Taiwan and Hong Kong. Control questions (seasons, Chernobyl, Watergate…) show each model's normal behaviour. A model that answers controls fully but refuses or thins out sensitive questions is filtering.

Method and limits

What counts as a refusal

An answer that opens with a refusal phrase in English or Chinese ("I can't discuss…", "抱歉…", "我们换个话题…"), one too short to contain any key fact, or a request the provider's content filter rejected outright (shown as "Blocked"). Answers cut off by length limits are re-run, not counted.

Key facts

Each question lists 2–3 facts a complete answer should mention, matched by keywords in all three scripts. Coverage is the share mentioned. Keyword matching is transparent but crude: it can miss paraphrases and cannot judge tone or framing.

Reasoning divergence

For models that return their reasoning, we flag answers where a key fact appears in the reasoning but not in the final answer: the model knew it and left it out.

Setup

Models are called through each provider's API (Groq, Zhipu, OpenRouter; the prefix in the model name), temperature 0, one sample per question, re-run regularly. Providers can add their own filtering, so results describe the model as served, not only the weights. v0.1 covers 4 models; more will be added as free capacity allows.
